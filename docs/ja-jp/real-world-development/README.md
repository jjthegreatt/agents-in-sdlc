現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を活用します。変更を計画し、コードを作成して動作をテストし、プルリクエストをレビューし、エージェントと作業を管理する反復的な開発を体験します。

## シナリオ

ボードゲームのクラウドファンディングを手がける架空の企業、Tailspin Toys の新しい開発者として作業します。チームのバックログは GitHub Issue として登録済みです。フィルタリングやページネーションなどの機能開発に加え、アクセシビリティやコーディング標準の改善にも取り組みます。

## 作業環境を選ぶ

GitHub Copilot は、さまざまな作業環境で利用できます。自分の開発スタイルに合った環境を選んでください。各ワークショップでは個別にセットアップを行い、Tailspin Toys のシナリオを使います。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan モードと Autopilot モード、instruction、skill、カスタム エージェント、Playwright MCP、Agent Merge、実践的なスラッシュ コマンドを扱います。

### [GitHub Copilot app][app]

デスクトップ アプリでエージェント セッションを並行して実行し、セッション モードを切り替え、Canvas 上で共同作業を行い、GitHub Issue とプルリクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub Issue を非同期エージェントに割り当て、作業を案内して進捗を確認し、エージェントが作成したプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに、Copilot Chat のエージェント モード、MCP server、カスタム エージェントを扱います。
